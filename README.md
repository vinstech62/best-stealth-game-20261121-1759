Shadow Gallery — a top-down stealth game: slip through a night museum, steal the artifacts and reach the exit unseen. Guards patrol with clear vision cones, bushes and shadows really hide you, and a detection meter (suspicious, alerted, caught) gives you a chance to recover before you are spotted. Three levels of increasing difficulty, synthesized WebAudio sound, no libraries, fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
